# Settings + Quests plugin (Paper 1.21+, Java 21)

## Команды
- `/settings` — меню настроек (ник, рост, GSit, пинг, PvP, уведомления)
- `/quests` (`/quest`) — главное меню заданий; `/quests daily|weekly|chains|ach|top|shop`
- `/shop` — магазин за руны
- `/runes` — баланс; `/runes top` — топ
- `/runes give|take|set|reset <игрок> [число]` — для админов (`settings.admin`)

## Новое в 2.1
- Правила: при входе игрок заморожен и видит книгу с правилами (время на чтение считается по таймеру,
  потом книга закрывается сама). `/rules` открывает ту же книгу, её можно закрыть когда угодно.
- Доступ к чужому: пока не выполнены задания (32 камня, 16 дерева, 8 железа, Незер, 15 минут),
  нельзя ломать блоки других игроков; чтобы открывать чужие сундуки и двери, нужно ещё 30 минут.
  Прогресс: `/access`. Обход: право `settings.bypass`.
- Косметика в магазине: больше следов, цвет ника, титулы в чате, эффекты убийства.
- Цепочка «Путь новичка» с наградами за те же задания.

## Что есть
- Ежедневные (по сложности 1-3), еженедельные, 6 цепочек по 5 шагов, 34 достижения
- 18 типов целей: добыча, постройка, урожай, убийства, рыбалка, крафт, плавка, еда, зачарование,
  размножение, приручение, стрижка, торговля, расстояние, время игры, измерения, уровень, advancements
- Руны, ранги (бонус к наградам), серия дней, бонус за все задания, топ игроков
- Магазин: ресурсы, временные бусты, частицы-следы, свои команды
- Скрытие стандартных сообщений входа/выхода (config.yml → join)

Все задания и товары лежат в `plugins/Settings/quests.yml` — правь свободно.
Если обновляешь плагин и хочешь новый quests.yml, удали старый из папки плагина.

## Сборка
Залей проект на GitHub → вкладка Actions → Build plugin → Artifacts → `Settings.jar`.
